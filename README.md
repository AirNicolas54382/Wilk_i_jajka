## 📖 About The Project

Inspired by classic retro handheld arcade games, this Java-based desktop application is an endless survival game. Four chickens positioned in the corners of the screen randomly shoot eggs toward the wolf in the center. The player must quickly reposition their pouch to catch the incoming eggs before they strike the wolf.

The game features dynamic difficulty scaling—the longer you survive, the faster the eggs travel, pushing your reaction time to the limit.

### ✨ Key Features
*   **Endless Scaling Difficulty:** The speed of the projectiles progressively increases over time, creating a challenging endless loop.
*   **Four-Way Defense:** Use keyboard inputs to instantly swap the pouch's position to one of four defensive angles.
*   **Catch Animations:** Includes visual feedback and custom animations when an egg is successfully caught in the pouch.
*   **Score Tracking:** Your current score (number of caught eggs) is tracked and updated in real-time.
*   **Sudden Death:** Missing a single egg results in an immediate "You dead" game-over state.

---

## ⌨️ Controls

Use the number keys to move the pouch and intercept the eggs from the corresponding chickens:
*   `1` - Catch Top-Left
*   `2` - Catch Top-Right
*   `3` - Catch Bottom-Left
*   `4` - Catch Bottom-Right

## ⚙️ Installation & Execution

To play this game locally, you will need **IntelliJ IDEA** and the Java Development Kit (JDK 17+ recommended).

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/AirNicolas54382/Wilk_i_jajka
    ```
2.  Launch **IntelliJ IDEA**.
3.  Click on **Open** and select the downloaded project folder.
4.  Allow the IDE a moment to index the files and configure the JDK.
5.  In the *Project Explorer*, navigate to the `src` folder, find your main class file, right-click it, and select **▶ Run**.
